DRILL BABY — Website

1. Open index.html to preview.
2. After launching, edit index.html and find the lines near the bottom:
   const TOKEN_MINT = '';
   const PUMP_URL = '';
   const DEX_URL = '';
3. Paste the real Solana token mint address into TOKEN_MINT.
4. Optionally paste the real Pump.fun and Dexscreener URLs.
5. Upload index.html and hero.jpg together to any static hosting provider.

The site will automatically display the address, copy button, Pump.fun link, Dexscreener link, and an embedded chart when a valid mint address is configured. The Dexscreener chart requires Dexscreener to have indexed the token and may not display immediately after launch.

No wallet connection or trading functionality is built into this website.
